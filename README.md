# Linear-Regression-Analysis-Multiple-variable

This repository contains a Machine Learning model that predicts YouTube video views based on multiple factors like the number of videos, days since upload, and subscriber count.

## 🚀 Project Overview
Unlike simple linear regression, this project uses **Multiple Linear Regression** to improve prediction accuracy by analyzing several independent variables simultaneously.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** * `Pandas` - Data loading and manipulation
  * `Scikit-learn` - Building the Regression model
  * `Numpy` - Mathematical operations

## 📊 Features Used (Independent Variables)
1. **Videos:** Total videos uploaded.
2. **Days:** Number of days since the channel started.
3. **Subscribers:** Total subscriber count.

**Target Variable:** `Views`

## 📁 Files in this Repository
* `Multiple variable.ipynb`: The main Jupyter Notebook with code.
* `Book2.csv`: The dataset used for training the model.

## 📈 Key Learnings
* Handling multiple features in a single model.
* Making predictions using `model.predict()` with DataFrame inputs.
* Understanding how more data points can lead to better predictions.
